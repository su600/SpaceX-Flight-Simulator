# SpaceX Flight Lab · 小小任务指挥官

**English version: [README.en.md](README.en.md)**

面向小小航天迷的三维火箭发射与回收模拟器。可以选择猎鹰 9 号、猎鹰重型或星舰，观看从点火、升空、分级到返航着陆的完整任务流程，并查阅模型尺寸、官网参考与画质记录。

全部模型与音效均在本地程序化生成，无需账号，不含收集信息、广告或付费功能。

![直播视图](public/quality/broadcast.png)

## 主要功能

- **三种火箭**：猎鹰 9 号、猎鹰重型（三芯 27 机）、星舰（33 机助推器 + 热分级 + 塔架捕获）。
- **完整任务阶段**：点火、升空、最大动压、分级、整流罩分离、返航点火、再入、着陆点火与着陆；可点击时间线任意阶段直接跳转。
- **手动分阶段**：每一阶段结束后等待指令，适合逐步讲解。
- **多种镜头**：跟随、全景、箭载、回收镜头，支持拖动旋转与滚轮缩放。
- **直播视图**：收起两侧指挥台，底部显示双级的速度、高度、发动机与推进剂余量。
- **中文语音讲解**：倒计时、阶段解说与发动机音效，声音默认关闭。
- **模型检视页**：可旋转查看迎风面、背面、机构近看与发动机视角，拖动滑块展开支腿或转动襟翼。
- **外形尺寸**：列出官网尺寸与当前模型近似值，并附襟翼、支腿、栅格舵、喷管等明细。

## 本地运行

需要 Node.js，建议使用启用了 WebGL / 硬件加速的现代 Edge 或 Chrome。

```bash
npm install     # 安装依赖
npm run dev     # 开发模式，http://127.0.0.1:4173
npm run build   # 构建到 dist/
npm run preview # 预览构建结果
```

Windows 上也可以双击 `Launch.vbs`（或运行 `Start-FlightLab.ps1`）自动启动并打开浏览器：脚本会按 `4173`–`4183` 顺序寻找可用端口，通过 `server.cjs` 只监听本机回环地址，再打开页面。便携版换到其他电脑时同样需要先安装 Node.js。

`dist/` 内的构建产物可部署到任意静态网站服务器，保留目录结构即可。`deploy/nginx.conf` 提供了一份部署示例。

## 模拟范围与声明

本项目是基于公开尺寸比例和可见结构制作的教育演示，与 SpaceX 无隶属关系，未使用官方 CAD 模型。

- 程序化模型包含发动机喷管、栅格舵、着陆腿、星舰襟翼与隔热瓦等细节，但尺寸为照片近似值。
- 屏幕上的任务时间与遥测为代表性示意数据，播放时间压缩为数分钟。
- 飞行轨迹与姿态按预设动画变化，风、云与海浪主要影响视觉，未进行真实六自由度气动、制导与燃料计算。
- 高空地球是具有高度相关曲率的独立背景层，不代表真实飞行位置或轨道。
- 参考构型为 Falcon 9 Block 5、Falcon Heavy 与官网 124 米星舰组合体，不宣称是最新 V3。
